## [1.6.7] - 2026-04-17

### ✨ Добавлено
- **Выгрузка уязвимостей**: кнопка "⬇ Скачать архив SBOM из Артифактори" — скачивание tar.gz архива SBOM выбранного артефакта
- **Выгрузка уязвимостей**: чекбоксы выбора проектов в таблице CodeScoring — фильтрация проектов при создании VEX файла
- **Выгрузка уязвимостей**: колонка "В SBOM" — зелёный бейдж для проектов, упомянутых в SBOM из Артифактори

### 🔧 Исправлено
- **Выгрузка уязвимостей**: исправлена логика `_in_sbom` — теперь сравнивается полное имя проекта CodeScoring (`LAM_1@oapi-lam-backend@file`) с `components[].name` в SBOM, а не только средняя часть имени

### ⚙️ Изменено
- **Docker**: образы обновлены до тега 1.6.7

## [1.6.5] - 2026-04-07

### ✨ Добавлено
- **Конвертер VEX**: кнопка "⬇ Скачать XLS с уязвимостями" — экспорт уязвимостей из CycloneDX SBOM/VEX JSON в Excel файл для передачи командам разработки
  - Столбцы: CVE ID, Компонент, Версия, Severity, CVSS Score, CVSS Vector, CWE, Описание, State, Разметка
  - Ячейки Severity окрашены по критичности (красный/оранжевый/жёлтый/зелёный)
  - Автофильтр, заморозка заголовка
  - Столбец "Разметка" содержит `analysis.detail` — заполнен для VEX файлов, пуст для чистых SBOM
- **Триаж VEX**: фильтр severity переработан с кнопок на чекбоксы с цветными бейджами — лучшая читаемость при всех включённых фильтрах

### 🔧 Исправлено
- **Конвертер VEX**: исправлен `API_URL = 'http://localhost:8000'` → `''` (относительный URL) — запросы теперь корректно проксируются через nginx в Docker окружении
- **Валидатор VEX**: аналогичное исправление API_URL

### 📝 Изменено
- **Backend**: новый endpoint `POST /api/sbom-to-xlsx` для генерации Excel из SBOM/VEX JSON
- **Docker**: сборка образов через `docker buildx build --platform linux/amd64` для корректной работы на x86_64 серверах при сборке на ARM Windows

## [1.6.2] - 2026-04-05

### 🔧 Исправлено
- **Конвертер VEX**: исправлено некорректное значение `justification: component_not_present` (не входит в CycloneDX 1.6 spec) — заменено на `state: in_triage` без justification
- **Выгрузка уязвимостей**: исправлена ошибка "Server disconnected without sending a response" для endpoint `/api/analyses/projects/history/` — заменён httpx/httpcore на stdlib `urllib.request` (отдельный HTTP стек без кэширования TLS-сессий)

### 📝 Изменено
- **Backend**: функция `_fetch_all_analyses` переписана на `urllib.request` (синхронно через `run_in_executor`) для обхода проблемы с TLS session caching в httpcore при работе внутри uvicorn

## [1.6.1] - 2026-03-28

### ✨ Добавлено
- **Модуль "Триаж VEX"**: новый инструмент для редактирования состояния уязвимостей в CycloneDX VEX файле
  - Загрузка VEX JSON через drag-and-drop или выбор файла
  - Редактирование State, Justification, Response, Detail для каждой уязвимости
  - Массовое применение State к выбранным уязвимостям
  - Валидация обязательного поля Detail перед скачиванием
  - Скачивание триажированного VEX файла

### 📝 Изменено
- **App.js**: переименование карточки "Vulnerability Report" → "Выгрузка уязвимостей"

## [1.5.0] - 2026-03-10

### ✨ Добавлено

## [1.0.0] - 2025-10-18

### 🎉 Первый релиз

#### ✨ Добавлено
- **Конвертер VEX**: конвертация CycloneDX SBOM (JSON) и XLSX в формат VEX
  - Поддержка фильтрации по проектам для XLSX
  - Экспорт в ZIP для нескольких проектов
- **Валидатор VEX**: валидация VEX документов по схеме CycloneDX 1.6

#### 📦 Зависимости (Backend)
- fastapi, uvicorn, python-multipart
- pandas, openpyxl, xlsxwriter
- httpx, python-dotenv, pyyaml

## Формат версионирования

Проект использует [Semantic Versioning](https://semver.org/):
- **MAJOR** (1.x.x) — несовместимые изменения API
- **MINOR** (x.1.x) — новая функциональность, обратно совместимая
- **PATCH** (x.x.1) — исправления
